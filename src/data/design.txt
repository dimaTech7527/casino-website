SWISS MODERN STYLE SYSTEM (MUST FOLLOW):

VISUAL CONCEPT:
- Grid-based precision and mathematical harmony.
- International typographic style.
- Clean, mathematical, grid-driven design.

BACKGROUND SYSTEM:
- White: bg-white
- Or very light: bg-gray-50
- Extreme cleanliness
- Example: <div className='bg-white'>

SURFACE SYSTEM:
- Strict grid: use grid system religiously
- Asymmetric balance
- Thin borders or none: border or border-0
- Example: 'grid grid-cols-12 gap-4'
- Minimal decoration: 'border-l border-gray-900 pl-8'

GRID SYSTEM:
- Use 12-column grid: grid-cols-12
- Asymmetric layouts: col-span-5, col-span-7
- Precise spacing: gap-4, gap-6, gap-8
- Strict alignment: items-start, justify-start
- Example: 'grid grid-cols-12 gap-6'

TYPOGRAPHY:
- Sans-serif only: default font
- Left-aligned: text-left (never center)
- Strong hierarchy: text-6xl for headlines, text-base for body
- Tight leading for headlines: leading-tight, leading-none
- Example headline: 'text-6xl font-bold text-gray-900 leading-none'
- Example body: 'text-base text-gray-700 leading-relaxed'

SPACING:
- Mathematical: use multiples of 4 or 8
- Negative space is critical: space-y-8, space-y-12
- Example: 'space-y-12 py-16'

BUTTONS:
- Minimal: 'border border-gray-900 text-gray-900 px-6 py-2 hover:bg-gray-900 hover:text-white'
- Clean transitions: 'transition-colors duration-200'
- Example: 'border border-gray-900 text-gray-900 px-6 py-2 transition-colors hover:bg-gray-900 hover:text-white'

INTERACTIONS:
- Precise, minimal
- Grid stays intact
- Clean purposeful transitions
- Example: 'transition-colors duration-200'

STRICT DO NOT:
- NO decoration
- NO centered text layouts
- NO playful elements
- NO colors beyond one accent + grayscale
